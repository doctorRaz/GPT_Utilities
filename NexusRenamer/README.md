# Nexus Markdown Export — Filename Fixer

Набор небольших утилит для исправления Markdown-файлов, экспортированных из ChatGPT с помощью Nexus.

## Проблема

При экспорте разговоров Nexus может создавать Markdown-файлы с именами, отличающимися от полного названия разговора.

Например, в экспортированном файле:

```markdown
# Title: Детерминированное разведение логов
```

но имя самого файла может быть сокращено:

```text
Детерминированное разведение лог.md
```

При этом индекс Nexus также использует сокращённое имя:

```markdown
[[Nexus/Conversations/chatgpt/2026/01/Детерминированное разведение лог.md|Детерминированное разведение логов]]
```

Это особенно заметно для названий, начинающихся с кириллицы.

## Что делает программа

Программа выполняет два шага:

1. Находит Markdown-файлы и переименовывает их согласно значению `# Title:`.
2. Исправляет wiki-ссылки в Markdown-файлах, чтобы они указывали на новые имена файлов.

### Пример

Исходный файл:

```text
Детерминированное разведение лог.md
```

Содержит:

```markdown
# Title: Детерминированное разведение логов
```

После обработки:

```text
Детерминированное разведение логов.md
```

А ссылка:

```markdown
[[Nexus/Conversations/chatgpt/2026/01/Детерминированное разведение лог.md|Детерминированное разведение логов]]
```

становится:

```markdown
[[Nexus/Conversations/chatgpt/2026/01/Детерминированное разведение логов.md|Детерминированное разведение логов]]
```

## Использование

Переименование файлов:

```csharp
var renamed = MarkdownTitleRenamer.Rename(@"D:\Obsidian");
```

Исправление ссылок:

```csharp
int updated = MarkdownLinkUpdater.Update(
    @"D:\Obsidian",
    renamed);
```

Либо для исправления уже существующего индекса:

```csharp
int updated = NexusIndexFixer.Fix(@"D:\Obsidian");
```

## Требования

* .NET
* Markdown-файлы в кодировке UTF-8
* Файлы должны содержать заголовок в формате:

```markdown
# Title: Название разговора
```

## Важно

Перед обработкой рекомендуется сделать резервную копию каталога с экспортом.

Программа изменяет имена файлов и содержимое Markdown-файлов.

## Назначение

Утилита предназначена прежде всего для подготовки экспорта ChatGPT/Nexus к дальнейшему использованию в Obsidian и других Markdown-хранилищах, где корректность внутренних wiki-ссылок зависит от фактических имён файлов.
