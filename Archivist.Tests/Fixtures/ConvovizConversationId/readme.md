# ConvovizConversationId

Файлы, экспортированные Convoviz, на которых обнаружена проблема
с определением `conversation_id`.

В наборе находятся два файла:

- `GPT_Archivist. Conversation_id.md` скопирован экспортом Archivist;
- Convoviz не смог определить `conversation_id` в `GPT_Archivist. Conversation_id.md` и создал `GPT_Archivist. Conversation_id (1).md`

Файлы предназначены для воспроизведения и диагностики бага. Вероятно баг в Convoviz?

На других файлах экспорта  Archivist >300 штук, Convoviz `conversation_id` определяет корректно

## Важно

Файлы являются исходными тестовыми данными и не должны изменяться
тестами или вручную в процессе выполнения тестов.

При необходимости тесты должны предварительно копировать файлы
во временный каталог.
