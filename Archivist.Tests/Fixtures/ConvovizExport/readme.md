# Фикстуры экспорта Convoviz

В этом каталоге находятся реальные Markdown-файлы, созданные Convoviz.

## Назначение

Файлы используются как тестовые фикстуры для Archivist.

Archivist читает эти файлы как исходные данные и в процессе обслуживания
архива может удалять их.

## Важно

Эти файлы **никогда не должны изменяться Archivist**.

В частности:

- YAML front matter не должен перезаписываться;
- содержимое Markdown не должно изменяться;
- имена файлов не должны изменяться.

Файлы представляют существующее состояние vault после экспорта Convoviz.

## Источник

Файлы скопированы из реального vault, содержащего экспорты Convoviz.

## Использование в тестах

Тесты, использующие эти фикстуры, должны рассматривать их как
данные только для чтения.

Если тесту необходимо изменить файл, сначала следует скопировать
фикстуру во временный каталог теста.
