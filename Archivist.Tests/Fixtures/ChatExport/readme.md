# Фикстуры Chat Export

В этом каталоге находятся реальные Markdown-файлы, полученные из
экспорта ChatGPT и обработанные Convoviz.

## Назначение

Файлы используются как входные фикстуры для pipeline импорта Archivist.

Ожидаемый процесс обработки:

ChatGPT export
→ Convoviz
→ Markdown-файл
→ Archivist
→ Vault

Archivist копирует эти файлы в vault и может изменять их YAML front matter
в процессе обработки.

## Сериализация YAML

Эти фикстуры используются для проверки десериализации и последующей
сериализации YAML.

Archivist должен:

1. прочитать YAML front matter;
2. десериализовать все поддерживаемые метаданные;
3. скопировать Markdown-файл в каталог назначения;
4. выполнить сериализацию YAML front matter в формате Archivist, только прочитанных данных и conversation_id;
5. сохранить содержимое Markdown без изменений.

## Важно

Эти файлы являются исходными данными.

Во время тестов содержимое копии файла в каталоге назначения может
изменяться, но сами файлы-фикстуры изменяться не должны.

Тесты должны сначала копировать фикстуру во временный рабочий каталог,
а затем выполнять над копией необходимые операции.

## Источник

Файлы извлечены из реального экспорта ChatGPT и обработаны Convoviz.

## Исходный формат YAML

Файлы содержат исходный YAML, сформированный Convoviz.

Формат исходного YAML намеренно сохраняется в фикстурах без изменений,
чтобы тесты могли сравнивать исходные данные с результатом обработки
Archivist и проверять корректность сериализации.
