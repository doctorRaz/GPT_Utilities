# Archivist

Утилита для обработки Markdown-файлов, экспортированных с помощью **[chatgpt-exporter](https://github.com/pionxzh/chatgpt-exporter)**.

## Возможности

- Обработка последнего ZIP-архива (или нескольких) с экспортом ChatGPT 
- Распаковка архива во временный каталог.
- Поиск экспортированных Markdown-файлов.
- Чтение метаданных из YAML front matter.
- Определение даты создания и изменения разговора.
- Организация файлов по каталогам `YYYY/MM`.
- Нормализация имён файлов:
  - замена `_` на пробелы;
  - удаление лишних пробелов;
  - сохранение символов Unicode, включая кириллицу.
- Проверка существующих файлов перед копированием.
- Сравнение метаданных исходного и существующего файла.
- Использование `chatLink` / `conversation_id` для идентификации разговора.
- Обновление файла, если экспортированная версия новее.
- Сохранение времени изменения файла (`LastWriteTime`).
- Защита от создания дубликатов.

## Принцип работы

1. Утилита находит последний ZIP-архив в исходном каталоге.
2. Распаковывает его во временный каталог.
3. Находит Markdown-файлы экспорта.
4. Читает YAML front matter и формирует `ChatMetadata`.
5. Определяет целевой каталог и имя файла.
6. Проверяет, существует ли файл назначения.
7. Если файла нет — копирует его.
8. Если файл существует — сравнивает метаданные и определяет, требуется ли обновление.
9. Для каждого разговора сохраняется только актуальная версия файла.

## Метаданные

Для работы с экспортированными разговорами используется типизированный класс `ChatMetadata`.

Основные поля:

- `CreateTime` — время создания разговора;
- `UpdateTime` — время последнего изменения;
- `ChatLink` — ссылка на разговор ChatGPT.

`conversation_id` может быть получен из `ChatLink` и не хранится отдельно в YAML.
